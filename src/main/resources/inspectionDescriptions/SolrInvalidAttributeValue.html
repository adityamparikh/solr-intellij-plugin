Reports an attribute whose value cannot be what the attribute accepts — indexed="yes", positionIncrementGap="foo", minGramSize="2.5". Solr rejects these when the core loads.

The kinds come from two places. A field's and a field type's properties are modelled directly; an analysis component's attributes are recovered from its constructor bytecode when the catalog is generated, which is also where the kind comes from — the method a factory used to read the value says what the value is.

The claim is narrow on purpose. This reports that a value is not of the right kind, never that a legal value is a poor choice: positionIncrementGap="-1" is an integer and is left alone.

Nothing is reported where the kind is not positively known, and a value containing ${...} is never judged — Solr's resource loader substitutes it, possibly from a system property set outside the repository.
