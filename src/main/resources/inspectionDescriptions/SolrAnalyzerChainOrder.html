Reports an analyzer component placed where the components above it have already made its work impossible.

An analyzer chain is a pipeline, and the order of its filters is the whole of its meaning. A mis-ordered chain is the hardest kind of schema defect to see: nothing is misspelled, every class exists, every attribute is legal, and Solr starts without complaint. The filter simply never does anything, and the only evidence is a search that quietly fails to match.

Two orderings are reported, both provable from the order alone:

  • A graph flattener above every filter that produces a graph. FlattenGraphFilterFactory flattens the token graph a SynonymGraphFilterFactory or WordDelimiterGraphFilterFactory emits, and a pipeline stage cannot flatten output produced after it runs. A chain that legitimately flattens twice, once after each producer, is not reported — the second flattener has a producer above it.
  • splitOnCaseChange below a filter that folds case. The option splits iPhone at the case transition; a LowerCaseFilterFactory above it has already turned that into iphone, so there is no transition left to find. The tokenizer counts too — LowerCaseTokenizerFactory folds as it splits.

The case-folding rule fires only on the attribute written in the file. Solr leaves splitOnCaseChange on unless set, so most chains with a lowercase filter above a word-delimiter filter are technically in this state, and their authors never asked for case splitting. Written, it is a stated intention the chain cannot honour.

Nothing is reported for an ordering that is merely unusual. Analyzer chains are where expert users deliberately do surprising things, and an inspection with opinions about style would fire constantly on chains working exactly as intended. No quick-fix is offered for the same reason: the repair is to move a filter, and which one to move is a question about intent.

Example: <filter class="solr.FlattenGraphFilterFactory"/> written above the <filter class="solr.WordDelimiterGraphFilterFactory"/> whose output it is meant to flatten.
