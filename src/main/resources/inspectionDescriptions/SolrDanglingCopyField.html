Reports a copyField whose source or dest names a field the configset does not declare.

Solr refuses to load a core with a dangling copy rule, so the failure arrives at deploy time rather than while the file is being edited. Until then nothing in the editor can see it: the reference is a bare string in an attribute, connected to the field it names by nothing but convention.

Field names containing * are not reported. A glob source is a pattern over dynamic fields, and whether anything matches it is not a question the schema alone can answer.

Example: <copyField source="manufacturer" dest="text"/> where no manufacturer field is declared.
