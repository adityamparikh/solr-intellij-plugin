Reports an attribute the element cannot accept — indexd="true", maxGramSiz="15".

These are worse than the mistakes Solr refuses to start on, because Solr ignores them. The field is simply not indexed, the gram size is simply the default, nothing fails, and the behaviour is quietly not what the file says.

This fires only where the set of legal attributes is genuinely complete: on <field> and <dynamicField>, and on an analysis component whose class the generated catalog knows.

It is deliberately silent elsewhere. A <fieldType> is never checked, because it delegates to classes its own configuration names — a providerClass selects the provider that reads currencyConfig — so its attribute list is open by construction. A component naming a class outside Solr is never checked either, which is how a custom plugin stays unflagged.
