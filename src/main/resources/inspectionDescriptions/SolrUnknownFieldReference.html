Reports a request-handler parameter in solrconfig.xml that names a field the schema does not declare.

This crosses the boundary between the two files, and it is the quietest failure in a Solr configuration. A qf naming a field that was renamed in the schema is not an error to Solr — the parameter is just a string. Queries return fewer results, or none, and nothing reports anything.

Only parameters known to name fields are examined: qf, pf, df, fl, sort, facet.field and their relatives. Function queries, globs, field aliases, parameter references and document transformers such as [docid] are not field names and are left alone, as are names Solr supplies itself such as score.

Example: <str name="qf">name^3 descriptoin</str> where the schema declares description.
